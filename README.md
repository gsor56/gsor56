## 🌸 What I'm Building

<div align="center">

<img src="https://capsule-render.vercel.app/api?type=soft&color=gradient&customColorList=6,11,20&height=60&section=header&text=FindFlower&fontSize=28&fontColor=fff&animation=twinkling&fontAlignY=65" width="70%"/>

<p align="center">
A premium, privacy-first flower identification app.<br>
Point a camera, get a species name back in seconds — <b>entirely on-device</b>.<br><br>
Powered by a <b>Hugging Face Vision Transformer (ViT)</b> for on-device inference, enriched with botanical data from the <b>Trefle API</b>, and cached locally via <b>IndexedDB</b> for instant, offline-ready lookups.<br>
No uploads. No servers. No compromise on privacy.
</p>
